## 多图与本地模型

本地 qwen3.8-27b 已通过图片输入探针，能读取测试图中的中文。实际长图使用单张图片逐页分析，保存顺序、原图SHA-256、送入模型图片SHA-256、模型/提示版本、失败状态；相同来源、图像、端点、模型配置与提示的成功结果可缓存，失败页可重试。

每篇默认最多20张图片；超过预算、图片缺失、哈希不匹配、模型失败均返回 partial 和缺失页码，不称为全量。相同图片出现在不同页码时保留两个位置，并标记重复，避免重复调用模型。长图机器识别可能漏字或跨页截断，8/8处理成功不等于全文转写准确率100%。

```bash
uv run rednotebook --db private/pilot/pilot.sqlite gallery-analyse --manifest private/pilot/media/ai-note/manifest.json
uv run rednotebook enrich --file private/pilot/evidence.json --gallery private/pilot/gallery-analysis.json --out private/pilot/evidence-with-gallery.json
```

`enrich` 仅匹配同来源、同笔记ID，输出新文件，不覆盖旧文件。应在首次导入该观察前合并；已入库的同一时刻观察不允许原地改写，历史修订规则仍有效。单图可用 `media-analyse --source … --file … --kind image`；可选 `media-extract` 调用 macOS Apple Vision 本地OCR。

`media_text` 与 `title`、`text` 分开引用，必须附带 `media_provenance`；研究网关明确提示它是机器提取而非作者原话。最终研究将逐页内容与正文、评论一起分析。

## 迁移、审核与清理

SQLite顺序迁移v2→v3（创作版本、审核、导出与outcome）→v4（manifest哈希）→v5（媒体分析缓存）。旧证据正文不重写。

审核绑定确切版本的内容哈希和审阅者。修订或素材改变生成新draft，不能继承批准；即使改回历史文案也产生新draft。只有重试完全相同的最新版本可复用。导出校验批准哈希、文件哈希及数据库保存的manifest哈希，拒绝目录穿越、受管目录符号链接和外链执行。渲染器为锁定的Pillow，中文字体使用本机PingFang/STHeiti或Noto CJK，缺少字体即失败。

`asset add` 复制用户明确声明权属的素材到版本内容中；源文件后续变化不改变已固定素材。图片完整缩放嵌入、不裁切，原始字节附在导出包供哈希校验。纯文字页面无需截图；声明了素材的页面缺少素材则拒绝。模型不会自行把公开笔记图片变为自有素材。

撤销/到期会使研究、创作版本不可读，并清空派生正文、媒体缓存、相关outcome和受管导出目录。输入文件、手工重定向保存的报告、浏览器临时下载与模型服务端留存不属于数据库受管清理范围。

## 复盘、适配器与暂缓项

`outcome import` 和 `retrospective` 实现实际时刻、24h±2h/72h±6h/7d±24h窗口、缺失值、重复冲突、公开/自有区分及用时记录。29h等迟到观察保留原时刻，不与准时窗口合并，不补造缺失指标。当前公开样本没有作者后台数据、精确发布时间或新内容发布，因此没有真实效果提升结论，A20未验收。

只读HTTP适配器仅允许小红书笔记GET路径，具有请求预算、缓存、401/403暂停、429最多两次重试、验证码停止、超时与字段漂移分类。它是**公开元数据适配器原型**，完整笔记/图片由本轮浏览器研究取得；不宣称已有稳定官方批量接口。浏览器登录或字段变化需要显式恢复，不绕过验证码。

视频原文件在用户暂停前取得，但没有继续进行视频/ASR验收。ASR模型下载已停止；faster-whisper移为可选依赖，默认安装和文字/图片流程不会下载ASR模型。
