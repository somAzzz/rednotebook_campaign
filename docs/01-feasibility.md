# 可行性分析

评估日期：2026-09-16。原方案作为需求输入，外部事实复核见 [资料核验](06-sources.md)。以下工期、预算、评分及阈值均为本项目初始假设，不是平台规则或行业基准。

## 结论

建议投入一个本地、单用户、导入优先的 MVP。证据整理、确定性计算、结构化研究、创意草稿与人工导出闭环，技术上可实现；“任意全站稳定采集”“准确预测爆款”“证明某种封面导致增长”不应作为交付承诺。项目最大的价值假设是能减少研究和创作返工，需真实试点才能证实。

| 环节 | 可行性 | 关键限制 | 第一版决策 |
|---|---|---|---|
| 授权 JSON/CSV 导入、证据与快照 | 高 | 字段及许可不统一 | 优先建设；坏行隔离、来源可追溯 |
| 指标比较 | 高，但解释受限 | 曝光、账号规模、投放因素常缺失 | 同口径同组比较，缺失即缺失 |
| 讨论与表达分析 | 中高 | 幻觉、样本偏差、评论截断 | 引用校验与人工标注集约束 |
| 基于真实产品生成创意 | 中高 | 产品事实及素材是否充分 | 事实台账；素材不足则列缺口 |
| 视觉分析 | 中 | 本地模型未验证，图像许可未知 | 独立能力探针；失败则人工描述 |
| 模板图文导出 | 高 | 中文字体、溢出、截图真实性 | 自有素材 + 确定性排版 |
| 浏览器自动研究 | 不确定 | 平台许可、登录、结构变动 | S8 可选，不阻塞 MVP |
| 自有后台复盘 | 高 | 归因和样本量不足 | 统一窗口，描述性分析 |
| 商业 SaaS | 尚不建议 | 数据合同、多租户、成本和责任边界 | 单用户验证通过后另立范围 |

## 对原方案的修正

1. 把“有来源”与“结论被来源支持”分开验收。引用能打开不等于推论成立。
2. 两套样本必须分开：热门样本用于表达研究；近期按固定规则取得的样本用于讨论观察。二者都不是全平台随机样本。
3. 100–200 篇不是起步门槛。先用 30–50 篇获准资料与 100–200 条评论跑通质量评估，再决定是否扩样；样本不足仍可输出带限制的报告。
4. “分位排序”会受组内规模与选择偏差影响。不可比时不给综合分；权重仅用于研究筛选，不能叫传播效率或爆火概率。
5. 审核绑定内容和素材哈希。MVP 在本地应用服务 + SQLite 中实现状态机，不先引入独立 Action Service、分布式队列或多 Agent。
6. 审批不能靠模型自报通过。多用户服务化之后还需认证、角色权限和服务端授权；本地文件系统所有者仍可改数据库，单机 MVP 不声称防御本机管理员。
7. CanDo 功能全部先登记为待验证。原方案描述不等同于当前产品事实；演示和发布日期需补证。
8. 规则检查只能标记可识别的问题及待审项目，不能承诺“通过检查即过审”。相似性检测也不等于版权结论。

## 投入估算与阶段决策

按 1 名熟悉 Python 的开发者、资料与模型可用估计：S1–S6 共 19–28 个有效工作日；加集成缓冲约 4–7 周。S7 真实试点另需 2–3 周日历时间。S8 每个适配器额外约 5–10 工作日，不含取得许可或供应商等待时间。不是固定报价。

默认用现有机器和本地模型，不采购 GPU 或付费数据。单次研究初始预算：最多 200 篇笔记、500 条评论、30 次模型调用、20 万输入 token、2 万输出 token；任一上限命中则部分完成并报告。预算需包括重试。云端模型只有数据许可明确时才启用；试点调用费用上限暂设 €20/月，供应商订阅和人工成本另计。

成本记录公式：输入 token × 对应单价 + 输出 token × 对应单价 + 数据源费用 + 渲染/存储费用；本地模型记录运行时间与硬件而不是虚构零成本。定价未核实前禁用成本预测。

在 S1 结束时审查数据可得性；S4 结束时审查研究可靠性；S7 结束时决定是否扩展自动研究。

| 风险 | 发现信号 | 应对与停止条件 |
|---|---|---|
| 没有足够获准资料 | 无可确认许可或关键字段 | 合成资料可做工程开发，真实研究暂停；不以爬虫代替许可 |
| 本地模型不可靠 | 两轮修正后引用精度仍低于 90% | 降级成证据整理与人工分析；不继续包装自动结论 |
| 数据偏差过大 | 作者集中、只含热评、组内过小 | 公开覆盖与限制，取消需求比例推断/综合排序 |
| 资料整理成本过高 | 三个试点均不比人工流程节省时间 | 缩减字段和功能，暂缓自动采集投入 |
| 接口不稳定 | 拒绝、验证码、字段漂移 | 停用适配器，继续导入路径 |
| 内容效果未证实 | 少量发布波动或指标缺失 | 记录“无法判断”，不追加爆款预测功能 |

## 首轮真实验证所缺材料

CanDo 当前可演示版本、功能清单及自有截图；一份允许存储和处理的研究样本；本地模型端点与型号；本人后台能导出的字段及使用范围。缺这些不阻碍项目初始化与合成数据开发，但阻止宣称真实研究或真实效果已经验收。
