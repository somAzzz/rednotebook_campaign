## 验证及下一步

全量 `uv run pytest -q`：220 passed。`uv sync --locked`、`uv run ruff check .`、`uv run ruff format --check .`、`uv run python scripts/check_scaffold.py`、`uv run python scripts/verify_foundation.py`通过。测试使用临时库、合成页面和确定性模型替身；不是本地模型或真实内容准确率验收。

优先优化方向：

1. **先完成逐页可核对证据**：在未来显式迁移中记录每页活动页位依据、资源身份、采集时间、下载哈希及原始尺寸，使“文件存在”与“页位正确”能独立复核。兼顾CDN地址变化和相同图片出现在不同页位，保持无法证明时拒绝放行。
2. **把运行前检查与后续工作拆开**：用户重新要求模型测试时，先做一次局部能力/连接检查，再开始整批分析；错误区分连接、服务拒绝、输出截断及图片不可读，保留成功缓存。不得后台自动探测或切换云端。
3. **提高图片阅读的可验证性**：长图/小字分块、逐字转写与摘要分离；由人工逐页核对数字、单位、否定词和表格。当前1280缩放路径与输出长度限制尚不能保证全文OCR。
4. **改善评论与范围提示**：区分确认无评论和未加载，采样UI展示原始指标缺失；相关性选择需另有可审计依据。候选不足30时提示实际缺口，不自动重复搜索凑数。
5. **恢复流程更具体**：让客户端可按错误类型展示补图、重新采集、恢复模型等明确步骤；保留用户确认边界，不让“成功采集”驱动“精读已完成”。补齐后台/失焦、轮播克隆与多种控件形态的离线回归矩阵。
